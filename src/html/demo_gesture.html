Supported Gestures

👆 Tap

Single touch/click without movement. Fires onTap callback.

👋 Swipe

Touch and drag in any direction. Detects left, right, up, down.

🤏 Pinch

Two-finger pinch gesture. Returns scale factor for zoom effects.

🔄 Rotate

Two-finger rotation gesture. Returns angle for rotation effects.

Usage

TouchGestureHandler

import { TouchGestureHandler } from 'move.gl'; const gesture = new TouchGestureHandler('myElement', { onTap: () => { console.log('Tapped!'); }, onSwipe: (direction, deltaX, deltaY) => { console.log(`Swiped ${direction}`); console.log(`Delta: (${deltaX}, ${deltaY})`); }, onPinch: (scale) => { console.log(`Pinch scale: ${scale}`); } }); // Clean up when done gesture.destroy();

AdvancedGestureRecognition

import { AdvancedGestureRecognition } from 'move.gl'; const advanced = new AdvancedGestureRecognition('myElement', { onGestureStart: (event) => { console.log('Gesture started', event); }, onGestureMove: (deltaX, deltaY, event) => { console.log(`Moving: (${deltaX}, ${deltaY})`); }, onGestureEnd: (event) => { console.log('Gesture ended'); } });

API Reference

GestureCallbacks Interface

interface GestureCallbacks { onTap?: () => void; onSwipe?: (direction: SwipeDirection, deltaX: number, deltaY: number) => void; onPinch?: (scale: number) => void; onRotate?: (angle: number) => void; } type SwipeDirection = 'left' | 'right' | 'up' | 'down';
