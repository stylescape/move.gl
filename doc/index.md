<h1 align='center' style='border-bottom: none;'>move.gl</h1>
</header>
<br/>

**move.gl** is a motion and animation library for the web. It ships:

- **Sass mixins and CSS classes** for animations, transitions, transforms, effects, hover and cursor controls, and loaders.
- **TypeScript components** for interaction: `Draggable`, touch and pointer gestures, a virtual keyboard, a screensaver, a transparent video overlay and a loader manager.

Animation classes respect `prefers-reduced-motion` by default.

Start with the [Quick Start](quick_start.md), then see the [Sass](guides/scss.md) and [TypeScript](guides/typescript.md) references.

**move.gl** is an open-source project by [Scape Press](https://www.scape.press 'Scape Press website').
